# Fun pictures

Drop AI-made pictures here (`.jpg`, `.png` or `.webp`). They appear automatically in the
"A lighter side" section of the home page, sorted by file name, and the section stays hidden
while this folder has no pictures.

Tip: name files like `01-astronaut.jpg`. The number sets the order and the words after it
become the caption ("astronaut") and the image description for screen readers. Portrait
pictures (4:5) look best; others are cropped to fit.
