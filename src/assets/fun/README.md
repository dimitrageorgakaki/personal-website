# Fun pictures

Drop AI-made pictures here (`.jpg`, `.png`, `.webp` or `.avif`). They appear automatically in the
"A lighter side" section of the home page, sorted by file name, and the section stays hidden
while this folder has no pictures.

Tip: name files like `01-astronaut.jpg`. The number sets the order and the words after it
become the caption ("astronaut") and the image description for screen readers. Pictures keep their own shape; nothing is cropped. For a longer caption and a full description for screen readers, add an entry to `captions.json`, keyed by the file name without its extension.
